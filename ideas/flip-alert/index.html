FLIPALERT

VIABILITY SCORE
MARKET · COMPETITION · EXECUTION
6.5/10

Real-time eBay listing monitor that compares new listings against recent sold comps, scores the profit opportunity (expected margin, days-to-sell estimate), and sends instant alerts when underpriced items appear. Targets the r/flipping (400K) and r/reselling (300K+) communities. $19–29/month. Pitched May 26, 2026.

R&D · SUBSCRIPTION · RESELLER COMMUNITY
THE GAP

Terapeak (eBay's own tool) shows historical sold data but has no real-time alert layer and no profit scoring. REPDASH and eBay seller analytics tools focus on seller performance tracking, not buy-opportunity alerts. No tool combines real-time new listing monitoring + sold comp scoring + email/push alerts specifically for manual resellers.

The r/flipping community is 400K strong and actively pays for tools. The workflow today is manual: check eBay, mentally compare to sold comps, decide. FlipAlert automates the comparison and brings the opportunity to you instead of making you hunt.

THE PRODUCT

Reseller sets up watch queries (categories, keywords, price ranges) → FlipAlert continuously monitors eBay new listings → compares each new listing against recent sold comps using eBay Browse API + Marketplace Insights API → scores profit opportunity → sends instant Slack/email/push alert when margin threshold is hit.

Pricing: $19/month (5 watch queries) or $29/month (unlimited). eBay Browse API and Marketplace Insights API are available officially.

COMPETITOR SWEEP
  • Terapeak — free with eBay seller account, historical data only, no alerts, no profit scoring
  • REPDASH — seller analytics (your own sales), not opportunity detection
  • Crosslisting tools (Vendoo, ListPerfectly) — cross-post inventory, don't find new inventory
  • POD trend tools (Listybox) — print-on-demand category, not general reselling

Gap confirmed: No tool combines real-time new listing monitoring + sold comp scoring + profit alert for manual resellers.

THE VERDICT
R&D · SUBSCRIPTION · PROVEN COMMUNITY WTP

The gap is real and the community pays. r/flipping regularly discusses tools and resellers pay for advantages. The willingness to pay is established — r/flipping community members treat their flipping as a business.

Main risk: eBay could shut down API access or Terapeak could add an alert layer. Build on official eBay APIs to reduce that risk.
